# Support HBM Modernized

**HBM Modernized** is an independent community port of *HBM's Nuclear Tech Mod* to modern Minecraft versions. This is a personal passion project - development takes a lot of time and effort. If you enjoy playing the mod, any support helps keep it moving forward.

Thank you!
